# Perfil GitHub via AJAX

Projeto simples que carrega e exibe dados de um perfil GitHub usando JavaScript, Fetch API e requisição AJAX.

## Funcionalidades

- Consulta dados do usuário diretamente da API pública do GitHub.
- Preenche avatar, nome, username, quantidade de repositórios, seguidores e seguindo.
- Atualiza link para o perfil oficial do GitHub.
- Tratamento de erros com mensagens no console e alertas ao usuário.
- Código assíncrono usando async/await e try/catch.

## Tecnologias usadas

- HTML5
- CSS3 (arquivo main.css)
- JavaScript (Fetch API)
- API pública do GitHub

## Como usar

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. O perfil será carregado automaticamente via AJAX.
4. Para mudar o usuário, altere a variável `username` no arquivo `main.js`.
